# Sage Intacct Premium redesign build

A dependency-free static implementation based on the supplied desktop/mobile exports, screenshots and motion clips.

## Preview locally

From this folder run:

```bash
python3 -m http.server 8080
```

Then open http://localhost:8080

## Deploy

This project is static and can be deployed directly to Vercel, Netlify, Cloudflare Pages, GitHub Pages, or any normal web host. The deploy directory is the project root.

## Included interactions

- Responsive desktop/mobile layout
- Hero background video
- Finance challenge selector
- Four capability tabs
- Customer video cards
- Expand/collapse industries
- Industry hover state
- FAQ accordion
- Responsive pricing/footer
